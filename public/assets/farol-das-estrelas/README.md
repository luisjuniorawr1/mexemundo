# O Farol das Estrelas — assets

Este diretório é o contrato de nomes do kit visual criado no Work. O jogo tenta carregar os PNGs listados em `manifest.json` e usa arte procedural de fallback quando um arquivo ainda não foi enviado.

Regras de entrega:

- backgrounds: 3840×2160, 16:9;
- personagens, objetos e UI: PNG transparente em alta resolução;
- sem halo branco, caixa residual ou contorno artificial;
- manter os nomes e subpastas do `manifest.json` para ativação automática no jogo.
